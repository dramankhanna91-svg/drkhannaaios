# C5. Surat patient machine (lean)

1. **GBP** — correct categories and services; 10 Q&As; weekly post; photos;
   review velocity via post-consult WhatsApp template; reply to every review.
2. **Ten condition pages** — spec in C2. Location pages only after 60 days of
   data and only where each page can carry unique, useful content.
3. **WhatsApp** — human-first intake on an official API using the existing
   structured forms. AI triage only after volume justifies it.
4. **Referral loop** — peer communication to physios, GPs and orthopaedists
   in referring towns; physician directory used professionally and opt-in.
5. **Content** — existing pipeline; v1's ten pillars retained; 2 posts +
   1 faceless video per week.
6. **Follow-up** — post-op milestone education, review request, recall.
   Opt-out everywhere.

## Metrics sheet (8 numbers, weekly)

GBP calls · WhatsApp leads · consults booked · show rate · surgeries booked ·
source of each surgery · opinions sold · opinion-to-visit conversion.

## Compliance box

Educational, factual, verifiable; no solicitation, comparative or outcome
claims; consented testimonials only; paid ads under the clinic/brand without
before/after imagery or condition-based targeting; DPDP consent and retention
on every form.
