# Clinical AI evaluation portfolio — Dr. Aman Khanna

Practising orthopaedic surgeon (arthroscopy, sports medicine, joint
replacement, trauma) · editor of an international orthopaedics journal ·
postgraduate training in statistics · Surat, India.

**Every case in this portfolio is synthetic.** No real patient data was used
in the preparation of any piece. These samples demonstrate the evaluation
work I provide to clinical-AI teams: rubric design, output auditing,
reasoning assessment, and documentation review.
